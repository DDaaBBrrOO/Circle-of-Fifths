📋 Планируемые изменения

1. Три концентрических кольца

Круг состоит из трёх колец:

  • Внешнее — мажорные аккорды (C, G, D, A, E, B, F#, Db, Ab, Eb, Bb, F)
  • Среднее — минорные аккорды (Am, Em, Bm, F#m, C#m, G#m, D#m, Bbm, Fm, Cm, Gm, Dm)
  • Внутреннее — уменьшённые аккорды (B°, F#°, C#°, G#°, D#°, A#°, F°, C°, G°, D°, A°, E°)

2. Подстрочные римские цифры

В каждом секторе круга для аккордов, входящих в выбранную тональность:

  • Сверху: название аккорда (крупный шрифт)
  • Снизу: римская цифра ступени (мелкий шрифт, полупрозрачный)

Пример: A с подстрочным I

3. Синхронизация подсветки

При выборе аккорда подсветка в круге синхронизируется с подсветкой в списке диатонических аккордов.

4. Поворот для минорных аккордов

При выборе минорного аккорда как тоники, круг поворачивается так, чтобы этот аккорд оказался на позиции 12 часов.
