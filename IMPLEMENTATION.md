- Кольцо расположено между средним кольцом (минорные аккорды) и центром

**Как работает:**

- Пример: для C мажор → B° (B diminished)

**Визуально:**
```

Среднее кольцо (140px) → Минорные аккорды
Внутреннее кольцо (100px) → Уменьшённые аккорды (НОВОЕ!)
Центр (65px) → Информация о тональности
```

### 2. Синхронизация подсветки

**Что сделано:**
- Подсветка в круге теперь синхронизирована с диатоническими аккордами
- Реализована функция `getChordHighlight()`, которая определяет:
  - Входит ли аккорд в текущую гамму
  - Какую ступень он представляет
  - Какой цвет использовать для подсветки

**Цветовая схема:**
- **Ярко-жёлтый** (`#FFD700`) — выбранный аккорд (тоника)
- **Прозрачно-жёлтый** (`rgba(255, 215, 0, 0.3)`) — мажорные аккорды гаммы (IV, V)
- **Прозрачно-бирюзовый** (`rgba(78, 205, 196, 0.3)`) — минорные аккорды гаммы (ii, iii, vi)
- **Прозрачно-красный** (`rgba(231, 76, 60, 0.3)`) — уменьшённый аккорд (vii°)
- **Тёмно-серый** (`#2d2d44`) — аккорды вне гаммы

**Пример для A Major:**
```
A  → ярко-жёлтый (I)
D  → прозрачно-жёлтый (IV)
E  → прозрачно-жёлтый (V)
Bm → прозрачно-бирюзовый (ii)
C#m → прозрачно-бирюзовый (iii)
F#m → прозрачно-бирюзовый (vi)
G#° → прозрачно-красный (vii°)
```

### 3. Подстрочные римские цифры

**Что сделано:**
- В каждом секторе круга для аккордов, входящих в гамму, отображается римская цифра
- Цифра отображается **в той же строке**, что и название аккорда
- Используется SVG `<tspan>` с атрибутами `dx="2" dy="3"` для подстрочного эффекта
- Размер шрифта цифры меньше основного текста (9px vs 14px для мажорных)

**Техническая реализация:**
```tsx
<text>
  {key}
  {highlight.highlighted && (
    <tspan
      fontSize="9"
      dx="2"
      dy="3"
      fill={isSelected ? '#1a1a2e' : '#FFD700'}
      opacity="0.7"
    >
      {highlight.roman}
    </tspan>
  )}
</text>
```

**Визуально:**
```
Aᴵ    Dᴵⱽ    Eⱽ    Bmᵢᵢ    C#mᵢᵢᵢ    F#mᵥᵢ    G#°ᵥᵢᵢ°
```

### 4. Исправление поворота для минорных аккордов

**Что сделано:**
- При выборе минорного аккорда как тоники, круг поворачивается правильно
- Реализована логика поиска соответствующего мажорного аккорда в круге квинт

**Как работает:**
```typescript
const rotationDeg = useMemo(() => {
  if (keyType === 'major') {
    const selectedIndex = CIRCLE_OF_FIFTHS.indexOf(selectedKey);
    return -(selectedIndex * 30);
  } else {
    // Для минорных аккордов находим мажорный аккорд,
    // для которого этот минорный является параллельным
    for (let i = 0; i < CIRCLE_OF_FIFTHS.length; i++) {
      const relativeMinor = getRelativeMinor(CIRCLE_OF_FIFTHS[i]);
      if (relativeMinor === selectedKey) {
        return -(i * 30);
      }
    }
    return 0;
  }
}, [selectedKey, keyType]);
```

**Пример:**
- Выбираем Am (ля минор) → круг поворачивается так, чтобы Am был на 12 часов
- Am является параллельным минором для C мажор
- C находится на позиции 0 в круге квинт
- Поворот: `-(0 * 30) = 0°`

```typescript
// Получить уменьшённый аккорд для мажорного аккорда
const getDiminishedChord = (majorKey: string): string => {
  const idx = getNoteIndex(majorKey);
  return NOTES[(idx + 11) % 12]; // 11 полутонов вверх = vii°
};

// Проверить, входит ли аккорд в текущую гамму
const getChordHighlight = (
  chordName: string, 
  type: 'major' | 'minor' | 'dim'
): { highlighted: boolean; roman: string; color: string } => {
  const diatonic = diatonicChords.find(d => d.name === chordName);
  if (diatonic) {
    // Определяем цвет в зависимости от качества аккорда
    let color = '#2d2d44';
    if (diatonic.quality === 'maj' && diatonic.roman !== 'I') {
      color = 'rgba(255, 215, 0, 0.3)';
    } else if (diatonic.quality === 'min') {
      color = 'rgba(78, 205, 196, 0.3)';
    } else if (diatonic.quality === 'dim') {
      color = 'rgba(231, 76, 60, 0.3)';
    }
    return { highlighted: true, roman: diatonic.roman, color };
  }
  return { highlighted: false, roman: '', color: '#2d2d44' };
};
```
